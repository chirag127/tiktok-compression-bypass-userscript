# TikTok Compression Bypass

Swaps the re-encoded stream for the highest-bitrate source TikTok already shipped to the page.

## Install

Follow the [install guide](https://github.com/chirag127/userscript-install-guide), then install:

```
https://github.com/chirag127/tiktok-compression-bypass-userscript/raw/main/tiktok-compression-bypass-userscript.user.js
```

## Usage

Open a video, press the HQ chip (Alt+Q), pick a source from the list. Nothing is downloaded.

## Limits

- Only offers encodes the page already received
- Switching restarts the buffer
- Live streams usually expose one source

## Risk

Gray: playback only, no re-hosting.
